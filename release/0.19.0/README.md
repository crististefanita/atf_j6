# Hold’em Lab 0.19.0

## Pe scurt

Ediția extinde Realizările la 39 de obiective specifice Texas Hold’em, cu criterii despre poziții, showdown, straturi de pot și parcursul turneului. Catalogul este măsurat separat pe Normal și Greu, la mese de 4–6 locuri.

## Descărcare

Calificarea este în curs. APK-ul va fi disponibil după verificarea buildului semnat și a probelor de instalare.

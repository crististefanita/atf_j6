# Modificări în 0.4.0

- Masa afișează numele și sumele tuturor beneficiarilor, inclusiv în fereastra compactă sau cu animațiile oprite.
- Marcajele premiilor urmăresc locurile beneficiare. Pariul neacoperit rămâne afișat separat de premiu.
- Poarta de promovare compară APK-ul cu identitatea verificată la instalare și respinge diferențele de sursă, semnare și checksum.
- Contextul RAG indică probele native afectate de schimbările din candidat. Documentația activă este separată de dovezile edițiilor.

# Hold’em Lab 0.4.0

## Pe scurt

Ediția 0.4.0 îmbunătățește prezentarea decontării și verificarea pachetului Android. Manifestul ediției deține starea calificării și identitatea pachetului.

## Distribuție

GitHub a publicat APK-ul și checksum-ul. Descărcările autentificate au trecut verificarea de integritate, iar poarta anonimă a rămas deschisă. Rezultatele separate sunt în manifest.

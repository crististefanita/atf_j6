# Hold’em Lab 0.19.0

## Pe scurt

Ediția extinde catalogul Realizărilor la 39 de obiective de Texas Hold’em: 14 Ușoare, 14 Medii și 11 Grele. Criteriile urmăresc pozițiile și blindurile, mâinile câștigate la showdown, poturile multiway, secundare și împărțite, eliminările, podiumul, heads-up și titlurile la turnee de 4–6 locuri. Obiectivele au praguri calibrate pe distribuiri de antrenare și holdout; exercițiile rămân în Antrenament.

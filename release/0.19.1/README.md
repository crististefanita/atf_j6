# Hold’em Lab 0.19.1

## Pe scurt

Această ediție aliniază popup-ul Realizărilor Hold’em la dialogul comun Card Table UI folosit în J4. Progresul salvat rămâne vizibil până la închidere, iar notificarea nu mai ocupă spațiu în masa de joc.

# Note de versiune 0.17.0

- Activezi sau oprești jocul automat din antetul mesei. În timpul turei adversarului, alegerea se aplică la următoarea ta decizie.
- Realizările acceptă căutarea după pragul afișat, păstrează filtrele și detaliul după recrearea ecranului și indică unde se câștigă progres.
- Actorul advers, blindurile, istoricul de pariuri și recomandarea coach-ului au text cu contrast mai bun.
- Pe ecranul compact, rezumatul decontării afișează numele și sumele tuturor câștigătorilor lângă antet.

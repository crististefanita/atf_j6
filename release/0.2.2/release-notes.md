# Modificări în 0.2.2

- Sumele și etichetele din chenare folosesc spațiul măsurat și păstrează contrastul la font mărit.
- Clasamentul afișează numele curent al profilului cu aceleași puncte și același număr de turnee după restart.
- Turneul încheiat intră o singură dată în clasament, inclusiv când jucătorul începe altul din meniu.
- Continuarea acceptată în timpul decontării se redeschide o singură dată după întrerupere.

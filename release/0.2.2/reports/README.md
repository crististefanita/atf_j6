# Dovezi de calificare

Calificarea leagă APK-ul semnat de commit, rezultatele JVM, lint și smoke-ul binarului instalat. Proba `seat-metrics` verifică chenarele unei mese cu șase locuri, font mărit și TalkBack activ. Rapoartele Extent încorporează capturile Android.

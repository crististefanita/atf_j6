# Note de versiune 0.2.0

- Chenarele compacte arată ultima acțiune sub fiecare jucător, cu jetoanele adăugate și accent pe mutarea cea mai recentă.
- Istoricul pariurilor se deschide la cerere și păstrează ordinea mutărilor, strada și contribuția cumulată până la mâna următoare.
- La decontare, combinația câștigătoare este evidențiată, iar premiul este direcționat vizual spre locurile care au câștigat din pot. Masa așteaptă comanda pentru mâna următoare.
- Clasamentul local cumulează punctele din turnee și folosește numele afișate la masă în sumarul rezultatului.
- Validarea checkpointului și a poziției din clasament rămâne compatibilă cu API 26. Clasamentul folosește etichete concise pentru punctaj și numărul de turnee.

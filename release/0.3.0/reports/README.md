# Dovezi de calificare

Runnerul califică sursa, componentele JVM, guvernanța, lint-ul, turneul determinist și smoke-ul binarului semnat. Rapoartele Extent încorporează capturile și aserțiunile native. Dosarul candidatului este extern până la promovare.
